# Definition of Done

DoD has two layers.

## Core DoD candidates
Apply only when relevant:
- Acceptance Criteria verified
- relevant error/edge behavior covered
- relevant tests completed
- regression impact checked
- backward compatibility checked
- security impact reviewed
- performance impact reviewed
- observability/logging updated or validated
- documentation/API contract updated
- migration/config/deployment concerns handled
- known risks/unknowns resolved or explicitly accepted

## Product-specific DoD
Load from the active Product Pack.

Do not blindly paste every Core DoD item into every story.
